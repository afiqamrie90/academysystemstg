3. Login

  1. Buka alamat ujian → bahagian Admin Login → taip password → Login.

4. Tab Players

Sama seperti v1.13.1 (tambah, Batch Add, Edit, Remove/Transfer, Reset kumpulan, View Details (Table), dropdown kategori yuran + Save All Fee Changes) dengan satu penambahan:

4.1 Position (GK / Outfield) BARU

  1. Dalam borang tambah pemain ada pilihan Position — Outfield atau GK.
  2. Pemain sedia ada: tekan Edit → pilih Position → Save.
  3. Senarai pemain menunjukkan lencana GK / OUT supaya mudah semak.
Kenapa penting. Position menentukan set kriteria yang dipakai semasa penilaian: GK → Goalkeeper criteria, Outfield → Outfield criteria. Kalau Position belum diisi, sistem pakai Outfield dan memaparkan amaran ⚠ — jadi isikan Position untuk semua penjaga gol sebelum menilai.

5. Tab Fees — pembayaran bulanan

Tiada perubahan daripada v1.13.1. Tab ini untuk menandakan siapa sudah bayar untuk bulan tertentu dan mengeluarkan resit. (Kategori yuran seorang pemain — RM120 / RM80 / Scholarship — ditetapkan di tab Players, bukan di sini.)

  1. Pilih Age Group, Month dan Year → tekan Load.
  2. Senarai pemain keluar bersama kategori yuran masing-masing dalam kurungan.
  3. Tandakan Paid atau Unpaid untuk setiap pemain.
  4. Tekan Save Payment Status — tanpa butang ini tanda anda tidak disimpan.
  5. Butang Receipt hanya muncul pada pemain yang berstatus Paid. Tekan untuk muat turun resit PDF (nama, kumpulan, bulan, jumlah, tarikh issued) — sesuai dihantar kepada ibu bapa.
Scholarship. Pemain berkategori Scholarship dianggap Paid secara automatik dan tidak boleh ditukar; resit mereka terbit dengan jumlah RM0.

6. Tab Attendance — sekarang hanya semak BERUBAH

  1. Pilih Date dan Age Group.
  2. Sistem memaparkan status setiap pemain sebagai teks (hadir / tidak) — tiada butang Present/Absent kerana jurulatih yang menanda di padang.
  3. Perlu betulkan kesilapan jurulatih? Tick Correct as admin → butang Present / Absent muncul → tekan yang betul → rekod terus tersimpan.
  4. Matikan tick itu semula bila selesai supaya tiada yang tertanda tanpa sengaja.
Muka 6 / 14

7. Tab Assessment — Assessment Criteria BARU

Tab ini hanya untuk mengurus kriteria penilaian (bukan untuk menilai pemain — itu di tab Reports).

7.1 Melihat kriteria

Setiap set dipaparkan dengan kategori, berat % dan senarai skill. Ada dua set: Outfield dan Goalkeeper. Satu set dipakai untuk semua kumpulan umur U8–U16 (kriteria ikut umur belum dibuat).

7.2 Menyunting kriteria

  1. Tekan ✏️ Edit pada set yang dimaksud.
  2. Boleh tukar nama kategori, berat % setiap kategori, tambah/buang skill, dan tambah/buang kategori. Jumlah berat dipaparkan hidup — kalau bukan 100% ia bertukar warna amber.
  3. Tekan Save Criteria.
Penilaian lama tidak rosak. Setiap penilaian yang disimpan menyalin snapshot kriteria pada waktu ia diisi. Jadi bila anda tukar nama atau berat skill, report card bulan-bulan lama masih keluar seperti asal — snapshot itu yang dicetak, bukan kriteria semasa.
Initialize / Reset Criteria menulis semula kedua-dua set kepada nilai asal kilang dan MENIMBUN suntingan anda. Ada pengesahan sebelum ia jalan. Guna hanya bila kriteria sudah bercelaru.
Muka 7 / 14

8. Tab Reports — dua mod BERUBAH

8.1 General Report (seperti dulu)

  1. Pilih Month, Year, Age Group → Generate Report.
  2. Pilih audiens Parents / Coach atau Management.
  3. Export to Excel (.xlsx) atau Export to PDF.

8.2 Player Report Card — nilai & muat turun report card BARU

  1. Tekan butang Player Report Card.
  2. Pilih Age Group, Year, Month (bulan penilaian) → pilih Player.
  3. Borang penilaian terbuka. Kriteria dimuat automatik ikut Position pemain (GK / Outfield).
  4. Tekan markah 0–5 untuk setiap skill, atau N/A kalau skill itu belum dinilai. N/A bukan 0 — skor komposit dikira daripada skill yang dinilai sahaja.
  5. Skor komposit + band keluar serta-merta di atas borang.
  6. Isi tiga nota: Strengths & observations, Focus area for next cycle, Recommendations.
  7. Tekan Save Assessment. Satu rekod setiap pemain setiap bulan (menyimpan kali kedua akan mengemas kini rekod bulan itu).
  8. Tekan Download Report Card (PDF) untuk muat turun kad.
Copy last month mengisi borang dengan markah bulan sebelumnya — anda tinggal ubah yang perlu. Berguna bila penilaian 15–20 pemain setiap bulan.

9. Apa yang ada dalam Report Card

Satu halaman A4 (hanya jadi 2 halaman kalau nota jurulatih sangat panjang), satu pemain:

BahagianIsi
HeaderJersi/crest kelab, nama akademi, bulan & tahun penilaian, kumpulan umur.
ProfilTeam · Position · Age (dari IC) · Criteria · Coach · Cycle.
Skill assessmentSetiap kategori (A, B, C, D) dengan purata markah dan berat %, senarai skill dua lajur — markah berwarna (hijau ≥ 4, amber ≥ 2.5, merah bawah 2.5). N/A dan belum diisi dibezakan.
Skor kompositNombor / 5.00 + band: Excellent · Developing Well · Good Start · Needs Development · Special Focus · Not Yet Assessed.
Attendance recordChip Present x of y (%) dan Absent n untuk bulan itu, dan di bawahnya tarikh absent disenaraikan (contoh: Absent on: 9 Nov · 23 Nov).
Coach feedbackNota strengths, fokus bulan depan, dan cadangan.
TandatanganNama jurulatih (dari tab Coaches) + tarikh issued.

10. Tab Coaches BARU

10.1 Coach Register

  1. Isi nama jurulatih untuk setiap kumpulan umur (U8–U16) → Save.
  2. Nama ini dipakai di dua tempat: header halaman coach ("Coach Page · U8 · Coach Xabi") dan tandatangan report card. Tiada lagi medan taip nama jurulatih dalam borang penilaian.
Ini catatan kelab sahaja. Register ini tidak mengawal login coach — sesiapa dengan coach code masih boleh masuk dan memilih kumpulan umur. Kalau register kosong, report card pakai "Coach, Shah Alam City Academy" dan header memaparkan "coach not set".

10.2 Coach Access Code BERUBAH

  1. Ada di bahagian bawah tab Coaches (dahulunya di tab Players).
  2. Taip code baru → Save Code. Status di bawah memaklumkan Coach code is active atau No coach code set — coach access is disabled.
  3. Kosongkan kotak lalu save untuk menutup akses coach.
Muka 10 / 14

11. Halaman Coach — dua tab BERUBAH

  1. Login guna coach code → pilih kumpulan umur. Header memaparkan kumpulan + nama jurulatih dari register.
  2. Tab Attendance — seperti dulu: pilih tarikh, tanda Present / Absent, tekan Save (wajib).
  3. Tab Assessment BARU — nilai pemain kumpulan sendiri: pilih tahun + bulan + pemain, tekan markah 0–5 atau N/A, isi nota, lalu Save Assessment. Kriteria dimuat ikut Position pemain.
  4. Halaman coach tiada butang muat turun report card — report card dikeluarkan oleh admin (tab Reports → Player Report Card).
  5. Selesai → Logout (dahulu bernama Back). Keluar akan memadam draf penilaian yang belum disimpan.
Pilihan tab coach diingati — reload halaman coach akan kembali ke tab terakhir yang dibuka.

13. Soalan biasa (v1.14.0)

MasalahSebab & penyelesaian
⚠ "Position not set for this player"Pemain belum dipilih GK/Outfield. Sistem pakai Outfield. Betulkan di tab Players → Edit.
"Criteria not found. Click Initialize first."Kriteria belum wujud pada database itu. Admin tekan Initialize / Reset Criteria di tab Assessment (sekali sahaja setiap database).
Skor komposit tak keluar / "Not Yet Assessed"Semua skill ditanda N/A. Sekurang-kurangnya satu skill mesti diberi 0–5.
Report card jadi 2 halamanNota jurulatih panjang. Normal — halaman kedua dapat header nama + bulan dan nombor halaman.
Nama pada tandatangan report card salah / "coach not set"Nama diambil dari tab Coaches. Isikan register kumpulan umur itu lalu Save.
Tarikh absent tak munculPemain tiada rekod tidak pada bulan itu, atau kehadiran belum ditanda. Kiraan hadir/tidak ikut bulan penilaian sahaja.
Report card tak ada butang muat turunButang itu hanya untuk admin (tab Reports → Player Report Card). Halaman coach memang tiada.
Penilaian bulan lepas bertukar selepas sunting kriteriaSepatutnya tidak — rekod lama pakai snapshot. Kalau berlaku, beritahu pembangun (itu kerosakan).
Perubahan tak nampak di skrinCache browser — tekan Ctrl+F5, dan pastikan badge STG/PROD mengikut pelayan yang anda maksudkan.
