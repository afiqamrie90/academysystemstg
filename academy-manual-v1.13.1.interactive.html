1. Sistem ini apa

Satu halaman web untuk menguruskan pemain, kehadiran, yuran bulanan dan laporan akademi. Semua data disimpan di cloud (Firebase) — buka di PC atau iPad, data sama.

Alamat (LIVE)https://apms.shahalamcityfc.com
PerananAdmin (pentadbir kelab) — semua tab. Coach — hanya tandakan kehadiran untuk kumpulan umurnya.
Perlu install?Tidak. Buka browser (Chrome / Edge / Safari) sahaja.
Perlu internet?Ya. Tanpa internet data tidak dapat dimuat atau disimpan.

2. Login

  1. Buka alamat di atas. Halaman pertama ada dua bahagian: Admin Login dan Coach.
  2. Admin: taip password kelab dalam kotak Password → tekan Login (atau tekan Enter).
  3. Coach: taip Coach code yang diberi admin → tekan Start → pilih kumpulan umur.
  4. Sesi kekal selagi tab itu dibuka — reload halaman tidak meminta login semula. Menutup tab, atau menekan Logout (admin) / Back (coach), menamatkan sesi.
Penting (versi ini). Belum ada akaun per-user. Password admin dan coach code adalah satu code yang sama untuk semua — siapa tahu code, siapa boleh masuk. Jangan sebarkan coach code di luar jurulatih. Menukar code: tab Players → bahagian bawah Coach Access Code.
Muka 2 / 10

3. Tab Players — daftar pemain

Tab ini untuk tambah, betulkan dan pindah pemain. Pilih Age Group (U8 / U10 / U12 / U14 / U16) dahulu — semua tindakan di tab ini hanya untuk kumpulan yang dipilih.

3.1 Tambah seorang pemain

  1. Pilih Age Group.
  2. Isi baru: Player name, No IC, Contact Parents (telefon ibu/bapa) dan Relation (BAPA / IBU).
  3. Tekan Add. Nama terus muncul dalam senarai.
No IC berguna. Sistem kira umur sebenar daripada 2 nombor pertama IC (tahun lahir). Ini yang dipakai untuk laporan dan paparan By Age. Pemain tanpa IC masih boleh didaftarkan, tetapi umurnya tidak dapat dikira.

3.2 Tambah ramai sekali (Batch Add)

  1. Tekan Batch Add.
  2. Taip satu nama setiap baris (salin dari Excel pun boleh).
  3. Tekan Save — semua nama masuk serentak.

3.3 Betulkan maklumat pemain

  1. Dalam senarai, tekan Edit pada pemain yang dimaksud.
  2. Kemas kini nama / IC / contact / relation → Save.

3.4 Padam atau pindah pemain

  • Tandakan kotak di depan nama (boleh ramai) → Remove Selected Players untuk buang, atau pilih kumpulan tujuan lalu Transfer Selected Players untuk pindah (contoh: U10 naik U12).
  • Naik umur tak perlu pindah satu-satu — guna Transfer Selected Players untuk satu kumpulan penuh.
Reset U8 Player List membuang SEMUA pemain dalam kumpulan itu (bukan seorang). Ia minta password admin. Gunakan hanya jika memang mahu kosongkan kumpulan. Sebaiknya buat senarai simpanan (salin ke Excel) sebelum reset.

3.5 Paparan lain

  • View Details (Table) — tukar senarai kepada jadual gaya Excel (BIL / Nama / No IC / Contact Parents / Relation / Fee / Actions).
  • Tab By Age — kelompokkan semua pemain ikut umur sebenar dari IC. (Tab ini sedang disembunyikan dalam versi ini.)

3.6 Tetapkan kategori yuran pemain

  1. Dalam senarai pemain, setiap baris ada dropdown - Select fee - / RM120 / RM80 / Scholarship.
  2. Pilih kategori untuk pemain yang perlu — sebaik ada perubahan yang belum disimpan, butang Save All Fee Changes muncul di bawah senarai.
  3. Tekan Save All Fee Changes untuk simpan semua pilihan sekali gus. Sebelum butang ini ditekan, pilihan belum masuk ke sistem.
  4. Kategori ini yang menentukan jumlah dalam tab Fees dan pada resit.
Muka 3 / 10

4. Tab Attendance — kehadiran

Dalam versi ini admin boleh menandakan kehadiran terus. (Mulai versi ujian v1.14.0, admin hanya menyemak — coach yang menanda di padang.)

  1. Pilih Date latihan dan Age Group.
  2. Senarai pemain muncul. Tekan Present atau Absent untuk setiap pemain.
  3. Tanda yang dipilih terus disimpan — tiada butang Save di bahagian admin. Tekan butang lain untuk betulkan kesilapan.
  4. Untuk lihat rekod hari lain, tukar tarikh.
Kehadiran juga boleh ditanda oleh coach melalui halaman Coach (bahagian 7). Dua-dua cara masuk ke rekod yang sama.
Muka 4 / 10

5. Tab Fees — pembayaran bulanan

Tab ini untuk menandakan siapa sudah bayar untuk bulan tertentu dan mengeluarkan resit. (Kategori yuran seorang pemain — RM120 / RM80 / Scholarship — ditetapkan di tab Players, bukan di sini.)

  1. Pilih Age Group, Month dan Year → tekan Load.
  2. Senarai pemain keluar bersama kategori yuran masing-masing dalam kurungan.
  3. Tandakan Paid atau Unpaid untuk setiap pemain.
  4. Tekan Save Payment Status — tanpa butang ini tanda anda tidak disimpan.
  5. Butang Receipt hanya muncul pada pemain yang berstatus Paid. Tekan untuk muat turun resit PDF (nama, kumpulan, bulan, jumlah, tarikh issued) — sesuai dihantar kepada ibu bapa.
Scholarship. Pemain berkategori Scholarship dianggap Paid secara automatik dan tidak boleh ditukar; resit mereka terbit dengan jumlah RM0.
Menukar tab atau menutup browser sebelum tekan Save Payment Status akan kehilangan tanda yang belum disimpan.
Muka 5 / 10

6. Tab Reports — laporan bulanan

  1. Pilih Month, Year dan Age Group → tekan Generate Report.
  2. Laporan muncul: kehadiran setiap pemain (hadir / tidak / peratus) dan status yuran.
  3. Pilih audiens:
    • Parents / Coach — ringkas, sesuai ditunjuk kepada ibu bapa.
    • Management — lengkap dengan angka untuk pihak pengurusan.
  4. Tekan Export to Excel (.xlsx) untuk fail spreadsheet, atau Export to PDF untuk dokumen siap cetak.
Pilih audiens sebelum export — butang yang aktif menentukan bentuk fail yang dimuat turun.
Muka 6 / 10

7. Halaman Coach (kehadiran di padang)

Ini yang jurulatih guna di padang — lebih mudah daripada tab admin.

  1. Buka alamat yang sama → bahagian Coach → taip Coach code → Start.
  2. Pilih kumpulan umur sendiri (U8 / U10 / …).
  3. Pilih tarikh latihan (default = hari ini).
  4. Tekan Present atau Absent untuk setiap pemain.
  5. Tekan Save — wajib, kalau tidak tanda tidak masuk rekod.
  6. Selesai → tekan Back untuk keluar.
Coach code dikongsi oleh semua jurulatih dalam versi ini. Kalau ada jurulatih berhenti, tukar code di tab Players → Coach Access Code → Save Code. Kosongkan kotak dan save untuk matikan akses coach.
Muka 7 / 10
